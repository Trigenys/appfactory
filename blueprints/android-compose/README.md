## Build

Use Android Studio or Gradle 9.6+ with JDK 21.

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

## Visual regression

When no golden baseline exists, the visual workflow records candidate screenshots and uploads them as an artifact. Review and commit the accepted PNG files under `app/src/test/screenshots/`. Later pull requests verify those goldens.

```bash
gradle :app:recordRoborazziDebug
gradle :app:verifyRoborazziDebug
```

The architectural reference is Android's Now in Android project; it is not copied or added as a runtime dependency.
