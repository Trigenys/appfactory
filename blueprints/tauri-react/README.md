# __APP_NAME__

Windows desktop application generated by Trigenys AppFactory.

## Baseline

- Tauri 2
- React + TypeScript + Vite
- Rust native command boundary
- GitHub Actions CI
- AppFactory Project Automation using GitHub Actions OIDC
- private-by-default repository provisioning

## Development

Prerequisites:

- Node.js 24+
- Rust stable
- Windows WebView2 runtime

```bash
npm install
npm run tauri dev
```

## Validation

```bash
npm run build
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo check --manifest-path src-tauri/Cargo.toml
```

## Security baseline

The generated frontend receives no broad filesystem capability. Product-specific access to local files should be exposed through minimal Rust commands with explicit validation.
